# External audit — 2026-09-07

One critical bug and five methodology/robustness defects, all fixed.
Full detail in `Brain.md` §34. Test suite: **72/72 passing, 0 failures**
(22 skipped for optional deps absent in the audit sandbox).

## 1. CRITICAL — paired reference contained the spectrum being classified

`paired.paired_features` subtracted `mean(ALL the patient's normals)`
from every row, *including the Normal rows that formed that mean*. Normal
rows were shrunk toward zero; Tumor rows kept full magnitude. The class
signal became row magnitude, not biochemistry.

On the real cohort (317 spectra / 72 patients):

| | zero rows | AUC of the row norm ALONE | Extra Trees macro-F1 / AUC |
|---|---|---|---|
| Before | 19 (all Normal) | 0.835 | 0.744 / 0.818 |
| After | 0 | 0.515 | 0.523 / 0.553 |

19 Normal rows were the exact zero vector. A single scalar scored AUC
0.835 — higher than the reported model AUC of 0.788.

Deployment was worse than the inflated score: `reference_vector()` builds
the predict-time reference from *other* files, so real normals arrive at
full magnitude. Simulated deployment predicted Tumor for **80% of Normal
spectra** vs 79% of Tumors.

**Fix:** leave-one-out reference. A Tumor row uses all of the patient's
normals; a Normal row uses that patient's *other* normals. Single-normal
Normal spectra are dropped (`n_normals_dropped`); their patient still
contributes Tumor rows. Degenerate cohorts now raise an actionable error.

**Action required: delete and retrain every paired `.joblib` saved before
2026-09-07.**

## 2. AUC confidence intervals ignored patient clustering

`bootstrap_ci` resampled patients; `delong_auc_ci` treated 2–5 spectra per
subject as independent, giving a materially too-narrow interval.
`delong_auc_ci(y, p, groups=...)` now runs a patient cluster bootstrap.
Point estimate unchanged.

## 3. The CI described a different classifier than the point estimate

Headline macro-F1 used the per-fold tuned threshold; its bootstrap CI used
`argmax` (a hard 0.5 cut). New `modeling.oof_predictions()` applies the
tuned threshold when one exists; used at all three call sites.

## 4. Winner's curse

`evaluate_models` reports the maximum over ~24 models scored on one set of
folds, then reuses those folds as the winner's performance and CI. Added
`modeling.nested_model_selection()` (model choice re-made inside every
outer fold) and `reproduce_study.py --nested-selection`. First
measurement, standard mode: pooled 0.530 vs **nested 0.504 ± 0.029**.

## 5. Ensemble members picked on the folds they are scored on

Not removable without nesting the whole registry per fold, so
`ModelResult.selection_biased` flags both top-3 rows and reports mark them.

## 6. `reproduce_report.py` XGBoost fallback never fired

`make(dim, None)` returns a Pipeline whose *clf step* is None, never None
itself, so the guard never matched and `cross_val_predict` raised instead
of degrading. Now inspects `named_steps["clf"]`.

## 7. Test-suite hygiene

`qt_compat` reported `No module named 'PySide6'` as though PySide6 alone
were required; now names all three bindings. The runner reports missing
optional deps as SKIP rather than FAIL — that miscounting hid the two real
failures. Two dependency-blind assertions fixed. Six regression tests added.
